# Learning TypeScript (TS)

## Overview
This repository is created to document my journey of learning **TypeScript**, a strongly typed superset of JavaScript. The purpose is to understand TypeScript fundamentals and apply them in real-world backend and web development projects.

TypeScript helps in writing clean, scalable, and maintainable code by adding static typing to JavaScript.

---

## Goals
- Learn TypeScript from basics to advanced concepts
- Understand the differences between JavaScript and TypeScript
- Improve code quality and reduce runtime errors
- Prepare for using TypeScript with Node.js and modern frameworks

---

## Topics Covered

### Basics
- Introduction to TypeScript
- TypeScript vs JavaScript
- Installation and setup
- TypeScript compiler (tsc)
- tsconfig.json

### Data Types
- string, number, boolean
- any, unknown, void, never
- Arrays and tuples
- Enums
- Union and intersection types

### Functions
- Function type annotations
- Optional and default parameters
- Arrow functions with types

### Objects and Interfaces
- Object types
- Interfaces
- Type aliases
- Optional and readonly properties

### Classes
- Classes and constructors
- Access modifiers (public, private, protected)
- Inheritance
- Abstract classes

### Advanced Concepts
- Generics
- Type narrowing
- Utility types
- Modules
